## Accessibility notes

A prior axe contrast failure was traced to sampling an entrance opacity animation mid-frame. Final static tokens were already AA-safe. The audit now runs axe under `prefers-reduced-motion: reduce` to inspect the stable rendered state, while a separate motion suite still verifies full-motion behavior. No production colors were weakened to silence the test.

## Performance notes

The single manifest is deliberately retained because the measured payload is far below the plan’s 2 MiB split threshold. Adding per-work chunks now would add request/orchestration complexity without measurable benefit.

Future optimization triggers:
- manifest exceeds 2 MiB minified;
- Web Vitals or Pages measurements show route startup regression;
- remote artwork becomes the dominant user-visible loading bottleneck;
- future editor/broker code materially increases the initial JS bundle.
