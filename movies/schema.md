# Схема данных кино

Файл `data/movies.yaml` — основной источник данных.

## Верхний уровень

```yaml
version: 1
rating_scale: 10
items: []
```

## Поля записи

```yaml
- id: interstellar-2014
  kind: movie
  title_ru: Интерстеллар
  title_original: Interstellar
  year: 2014
  status: watched
  rating: 9.5
  rating_source: inferred
  confidence: high
  comment: "Большой плюс"
```

### `kind`

- `movie` — отдельный фильм
- `series` — сериал
- `collection` — оценка серии/франшизы целиком, когда в разговоре части не были оценены отдельно

### `status`

- `watched` — просмотрен
- `unwatched` — не смотрел
- `dropped` — начал, но не досмотрел
- `forgotten` — смотрел давно, недостаточно помнит для оценки
- `partial` — просмотрена только часть серии/коллекции

Статус не является оценкой.

### `rating`

Личная оценка от `1` до `10`, допустим шаг `0.5`. Если данных для оценки нет — `null`.

Ориентиры:

- `9–10` — большой плюс / фаворит / многократные пересмотры
- `8–8.5` — очень хороший
- `7–7.5` — хороший
- `6–6.5` — нормально
- `5–5.5` — на один раз / много оговорок
- `4–4.5` — скорее не понравился
- `1–3.5` — плохо

### `rating_source`

- `explicit` — пользователь назвал число или очень явно задал уровень
- `inferred` — число восстановлено по словам вроде «хороший», «норм», «отлично»
- `none` — оценки нет

### `confidence`

- `exact` — точная числовая оценка
- `high` — сильный и однозначный словесный сигнал
- `medium` — обычная приблизительная интерпретация
- `low` — оценка особенно приблизительна
- `none` — оценки нет

### `comment`

Сохраняет исходный смысл отзыва и нюансы, которые нельзя выразить одним числом.

## Принцип редактирования

При ручной корректировке оценки достаточно поменять `rating`. Если новое число выставлено самим пользователем, желательно также поставить:

```yaml
rating_source: explicit
confidence: exact
```
