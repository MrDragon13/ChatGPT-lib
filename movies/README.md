# Кино

Этот раздел хранит результаты киноопросов и используется как база для будущих рекомендаций.

## Структура

- [`data/movies.yaml`](data/movies.yaml) — **единственный источник истины**: статус просмотра, личная оценка и комментарий по каждому фильму/серии.
- [`profile.md`](profile.md) — аналитические выводы о вкусе. Здесь не дублируется полный список фильмов.
- [`schema.md`](schema.md) — описание формата данных и шкалы оценок.

## Главное правило

`unwatched`, `forgotten`, `dropped` и `partial` сами по себе не являются отрицательной оценкой. Оценка хранится отдельно в `rating`.

## Текущая шкала

Оценка — от **1 до 10** с шагом 0.5.

- 9–10 — большой плюс / фаворит / хочется пересматривать
- 8–8.5 — очень хороший фильм
- 7–7.5 — хороший
- 6–6.5 — нормально, но без сильного восторга
- 5–5.5 — скорее на один раз / заметные оговорки
- 4–4.5 — скорее не понравился
- 1–3.5 — плохо
- `null` — оценки нет

Большинство оценок первого импорта восстановлены по формулировкам из разговора и помечены `rating_source: inferred`. Их можно спокойно править вручную.
