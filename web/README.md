# Media Web

`web/` — статический React/Vite-интерфейс медиатеки, который публикуется через GitHub Pages. Он читает версионированный производный manifest и не является отдельным источником данных.

Исходные данные медиатеки живут в `media/`. Клиент не читает и не меняет YAML напрямую. Поддерживаемые правки отправляются через Broker, который преобразует их в `record_media_entry` и передаёт в общий v6-путь записи.

Если по одному `work/target` уже выполняется запись, Web не отправляет вторую параллельную операцию. Пользователь может продолжать менять локальный черновик; после публикации первой операции Web обновляет manifest и разрешает отправить следующее изменение.

Пустая библиотека остаётся поддерживаемым состоянием: Home, Library и History должны показывать понятное состояние пустой библиотеки, а не фиктивные произведения.

## Локальная проверка

```bash
npm ci
npm run test:run
npm run typecheck
npm run build
npm run scan:dist
```

Проверки браузера, адаптивности и доступности запускает процесс `Web Check`. В собранном браузерном коде не должно быть GitHub-токенов, ключей провайдера или других секретов.
